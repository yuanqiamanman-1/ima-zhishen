# 01 使用说明｜浙大校园信息站

> 这里汇集浙大学习、办事与校园生活信息，既有官方资料，也有有来源的校园经验。请结合资料来源与日期判断，重要事项以学校最新通知为准。

## 这里能帮你找什么

- 入学报到、校园卡、账号、校园网和常用系统
- 选课、考试、图书馆、竞赛、科研、奖助与升学
- 宿舍、食堂、快递、校内交通、体育、社团和杭州生活

直接把问题问给知识库 AI 即可。可以尽量说清你的校区、身份和场景，例如：

```text
紫金港的新生怎样开通校园网？
本科生想找选课和考试相关资料。
有哪些关于食堂和快递的校园经验？
```

## 怎样看待搜索结果

- 标有来源和日期的资料通常更容易判断是否仍适用。
- 官方资料适合确认规则、通知和办事要求。
- 经验资料适合参考生活、学习和办事技巧；它不等同于学校规定。
- 遇到报名截止、资格认定、费用、医疗、安全、权益等重要问题，请打开原始来源并以学校最新通知为准。

## 发现问题或想补充资料

请把原始链接、文件或问题说明交给邀请你的协作者或知识库管理员。普通订阅者不需要 API Key，也不需要安装 Skill。

本库持续整理中；欢迎使用，也欢迎帮助它变得更好。
