# 多来源经验整理原生笔记模板

仅用于把两份及以上可追溯来源整理为一篇面向学生的 ima 原生笔记。正文按主题自由组织，但必须充分保留可检索的具体信息；不要压缩成群公告式短摘要。

```markdown
# {YYYY-MM-DD}｜{主题}｜{适用范围}｜经验整理

> 资料性质：基于可追溯学生经验与原始材料整理，非原帖转载。
>
> 适用范围：{校区 / 年级 / 身份}
>
> 时效情况：{当前官方材料年份；经验来源主要年份；必须当日复查的动态事项}
>
> 使用提醒：本文中的经验不等同于学校规则；政策、资格、时间、费用、班次、地点等，以当前原始官方材料和系统结果为准。

{详细正文：自由组织；保留操作路径、别名、条件、例外、风险和当日复查入口。}

---

## 来源

### CC98 经验来源

- CC98｜《{帖子标题}》｜楼主：{用户名}｜{YYYY-MM}｜Topic {编号}

### 原始材料

- {发布机构}｜《{文件 / FAQ / 页面标题}》｜{公开链接}
```

规则：

- 标题日期表示本次整理或核验日期；时效情况必须区分“主题容易变化”和“现有来源是否新”。不要在来源行重复 CC98 的日级日期。
- 一个 Topic 只写一行；不另列评论、楼层、评论者或 CC98 内网链接。
- 原始材料必须是实际用于正文的原始官方/公开页面、文件或 FAQ，不是搜索工具、聊天助手或其他发现渠道。
- 若原始材料存在当前规则与旧通知冲突，以当前原始材料为准；无法判定时写明限制或转入 `98`。
- 原生笔记创建回执必须保存完整标题、前 24 个字符的稳定标题段和目标目录；ima 搜索可能把长标题显示为省略号，恢复关联时按该稳定标题段匹配，不能因为完整标题查不到就重复创建笔记。
